# CrackScan Mobile (Capacitor)

Android app that wraps the CrackScan web client in `www/` and talks to the Flask
server in the repository root. Photos and live frames are analysed **on the
server** (YOLOv8-seg), not on the phone, so the phone only needs the network.

```
mobile/
├── www/                 the whole UI (plain HTML/CSS/JS, no build step)
├── resources/           icon / splash sources + generator script
├── capacitor.config.json
└── android/             native project generated by `npx cap add android`
```

## Screens

| Screen | What it does |
|---|---|
| **Scan** | Live camera preview with the detected crack drawn on top (calls `POST /analyze_live` about once a second). Shutter = analyse the current frame (`POST /api/mobile/scan`), long-press the shutter = native camera photo, **Gallery** = pick a photo. |
| **History** | Saved scans from the server (`GET /api/cracks`), filterable by inspection status. Tap a scan for the annotated picture, measurements, brick-wall badge, and inspection actions. |
| **Server** | Server address, connection test, model/version info. |

Everything the app stores (server address) lives in `localStorage`.

## Requirements

* Node 18+ and npm
* Android SDK (build-tools + a platform)
* **JDK 23** — Capacitor 7 compiles for Java 21 and its Gradle 8.11.1 wrapper
  needs a modern JDK. (JDK 17 fails with `invalid source release: 21`;
  Android Studio's bundled JBR 25 is too new for Gradle 8.11.1.)

## Build the APK

```bash
cd mobile
npm install

npx cap sync android

# Windows (PowerShell), adjust the JDK path if yours differs
$env:JAVA_HOME = "C:\Program Files\Java\jdk-23"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
cd android
.\gradlew.bat assembleDebug
```

The APK lands in `android/app/build/outputs/apk/debug/app-debug.apk` (~7 MB).

Open it in Android Studio instead with:

```bash
npx cap open android
```

## Run it without building

The server already serves the same web build:

```
http://<pc-lan-ip>:5000/app/
```

Open that on the phone's browser to try the UI before installing anything.

## Point the app at the server

On first launch, open the **Server** tab and enter the PC's LAN address, e.g.
`http://192.168.1.20:5000` (the Flask startup banner prints it). Keep the phone
and the PC on the same Wi-Fi.

The app needs plain **HTTP** to reach a LAN server:

* `capacitor.config.json` → `server.cleartext: true` and
  `android.allowMixedContent: true`
* `AndroidManifest.xml` → `android:usesCleartextTraffic="true"`

If you put the server behind HTTPS, those can be turned off.

## Common tasks

```bash
# after editing www/ (Capacitor copies the folder into the native project)
npx cap sync android

# change id / name
#   capacitor.config.json → appId, appName

# regenerate launcher icons + splash from resources/*.png
python resources/make_assets.py
npx @capacitor/assets generate --android

# iOS (needs macOS + Xcode)
npm i @capacitor/ios && npx cap add ios && npx cap sync ios
```

## Permissions

`CAMERA` is declared for the live preview (`getUserMedia` inside the WebView) and
the native camera sheet; `INTERNET` is standard. The camera is only opened when
you press **Enable camera** or use the shutter.

## API used

| Endpoint | Purpose |
|---|---|
| `GET /api/mobile/health` | handshake + model/version |
| `POST /api/mobile/scan` | analyse + save a photo (multipart or base64) |
| `POST /analyze_live` | analyse a preview frame (not stored) |
| `GET /api/cracks?limit=&images=0` | history |
| `PATCH /api/cracks/<id>` | inspection status |
| `DELETE /api/mobile/records/<id>` | delete a scan |
